Little Monsters Fan Registration System

School project built with HTML, CSS, JavaScript, and Bootstrap 5.

Files:
- index.html: page layout
- style.css: black-and-white design
- script.js: fan registration, album tracklists, search, edit/delete, and dashboard statistics

Run: Extract the folder, open it in VS Code, then open index.html in a browser or use Live Server.

Internet is needed for Bootstrap, Google Fonts, and remote images. Fan records are stored in this browser using localStorage; no database is connected.
